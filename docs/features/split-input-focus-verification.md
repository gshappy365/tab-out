# 分屏输入焦点：实现与 LCU 验收

日期：2026-10-16。基线：split-screen，1.2.0（18eb41c）上的本地开发改动，manifest 版本未升级。

## 结果

已实现：已有分屏中，鼠标点击和遥控器确定激活浏览侧真实标签；成功返回也激活起始浏览标签。菜单继续聚焦总览；遥控方向命令继续控制总览选择，普通键盘输入交给浏览侧。

扩展依靠 Chrome 对已有页面编辑焦点的保留机制，没有新增权限、网页脚本、输入内容读取或保存，也不猜测首个输入框。

## 代码变更

- split-navigation.js：成功选择、重复选择及返回聚焦目标标签；窗口 ID 取自激活后的真实标签，避免跨窗口移动后聚焦旧窗口。失败恢复仍沿用总览焦点。
- remote-background.js：选择或返回成功的 remote:show 消息声明 focusDashboard: false；菜单消息沿用总览焦点。
- remote-dashboard.js：只在菜单等需要总览焦点的消息中调用 window.focus()，刷新或方向选择不主动抢焦点。

## 自动化验证

Chrome for Testing 155.0.8059.84，完整测试 **36 项通过，0 失败、0 跳过**。包含普通标签行为回归、左右侧布局、跨窗口及目标已有分屏、失败恢复，以及以下新增检查：

- 恢复第二个输入框，保留中间光标并续写；第一个输入框保持为空。
- 重新选择当前浏览标签，保留文本选区并替换选区。
- 没有原输入焦点时只激活网页，不挑选首框。
- 菜单回总览、方向命令不切焦点、返回后在 A 的原位置续写。
- 跨窗口移动后正确聚焦目标当前所在窗口。

JavaScript 语法检查、git diff --check 通过。项目没有包管理器依赖清单，未引入第三方依赖，因此 npm/pip 依赖审计不适用。

## LCU 本机验收

实际运行：Google Chrome **155.0.8059.82 arm64**，macOS 14.7.3。通过 LCU 在独立测试窗口操作本地 A/B 页面；每页均有第一个 input 与第二个 textarea，未提交任何数据。

验收直接使用 Chrome 原生鼠标、键盘和 AX 状态；切换后不点击浏览侧输入框、不调用网页 focus 脚本、不通过设置值代替输入：

| 操作 | 实际结果 |
| --- | --- |
| B 第二输入框预置 B-BASE，光标放在 E 前；总览鼠标点击 B，待 AX 显示切换完成后键入 -CLICK- | AX 焦点为 B 原输入框；值变为 B-BAS-CLICK-E；第一个输入框仍为空 |
| 菜单后按确定快捷键，再直接键入 -OK- | 焦点回 B 原输入框，值变为 B-BAS-CLICK--OK-E |
| 返回后直接键入 -BACK- | 恢复 A 原输入框，值变为 A-BAS-BACK-E |
| 普通 Left 后键入 K，再发送遥控方向命令并键入 -DIR- | A 光标移动生效，值为 A-BAS-BACKK-DIR--E；方向命令未抢输入焦点 |
| 从 A 经总览选 B，按确定快捷键并直接键入 -SWITCH- | B 值为 B-BAS-CLICK--OK--SWITCH-E，原草稿保留 |
| 选中 B 最后一个 E，菜单后重新确定 B，再键入 SEL | B 值为 B-BAS-CLICK--OK--SWITCH-SEL，原选区正确恢复 |
| 最终跨窗口修正加载后，在总览点击 A，再菜单/确定 A，待切换完成后直接键入 -FINAL- | 焦点仍为 A 原输入框，完整标记出现在原光标位置；总览在左、浏览侧在右 |

菜单的 AX 焦点明确为总览 HTML content。两侧位置均在本机过程中出现，最终保留总览左侧、A 右侧供查看。

## 实际边界

- 分屏重组是异步操作。需等目标已显示并获焦后再输入；曾在同一个自动化批次中紧接点击立即发送字符，切换完成前的前几个字符未进入目标输入框。不会缓存或重放这段过早输入。本验收以 AX 确认切换完成后无需额外点击即可输入为准。
- 测试涉及本地标准输入框、textarea；没有承诺任意网站的 iframe、Shadow DOM、主动改焦点脚本或已删除输入框均能恢复。若遇到具体网站不能恢复，再讨论按网站授权方案。
- 遥控器命令使用真实绑定快捷键验证，未进行实体遥控器 / SayAll 完整链路验收。
- 本机已加载本地改动，保留 config.local.js 及快捷键。原三份代码备份在工作区的 lcu-input-focus-backup-1.2.0。
- 重新加载扩展后其他新标签扩展可能接管 chrome://newtab，本机最终使用遥控扩展的直接 index.html 地址验收。测试过程中一次导航/刷新重置了 B 测试页，最终又在保留草稿的 A 上补验；没有重载业务网页。
